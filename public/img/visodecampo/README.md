# Renders de Viso de Campo

Set final (octubre 2026), según el brochure `Brochure_VisodeCampo.pdf`. WebP, hasta 1920 px, calidad 85.

## Predio y SUM
| Archivo | Brochure | Uso en la web |
|---|---|---|
| ext-ingreso | Portada / ingreso | Portada, parada 1 del predio |
| ext-unidades | Exterior módulos | Parada 2, amenities |
| ext-parque | Área central | Parada 3, sección Proyecto, amenities |
| ext-pileta | Piscina | Parada 4, amenities |
| sum-cowork | SUM + gimnasio (cowork) | Parada 5, amenities |
| sum-gym | SUM + gimnasio | Parada 6, amenities |

## Planos
| Archivo | Uso |

Fuentes de marca en `/public/fonts`: La Centa (títulos) y Copperplate Gothic (etiquetas y logotipo).

Hay dos versiones de la web: `/visodecampo` (diseño clásico, principal) y `/visodecampo-moderna` (diseño moderno). Ambas comparten estos archivos.
